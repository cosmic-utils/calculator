# History
The calculator has an operations history, providing the ability to bring previous calculations back to the screen for further use or inspection.

# Modes
The keypad grows with the window: widen it to reveal the scientific functions, and widen it further for statistics. To keep a mode regardless of the window size, pick it from the View menu; Automatic Mode goes back to following the window width.
